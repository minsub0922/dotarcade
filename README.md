# 🕹️ DOTCADE (도트케이드)

> **게임 스튜디오 운영 + 오락실 배포 시뮬레이션.** 플레이어는 도트 게임 스튜디오의 팀장이 되어, LLM 멀티에이전트 팀원들과 BMAD 방식의 회의로 *실제로 동작하는* 도트 미니게임을 만들고, 오락실에 배포해 20명의 가상 손님 에이전트로부터 피드백과 점수를 받습니다.

## 핵심 루프

1. **회의 = 제작** — AI 팀원 5명(PM·시니어/주니어 개발자·디자이너·작가)이 BMAD Method 10단계 회의로 동작하는 게임팩을 산출
2. **배포 = 검증** — 오락실 맵에서 20명의 가상 손님이 게임을 실제 실행·플레이하고 점수·피드백 제공
3. **반복 = 성장** — 피드백 → 업그레이드 회의 → 버전 업(게임별 실제 git 커밋·태그) → 재배포

## 구성

| 폴더 | 스택 | 포트 | 설명 |
|---|---|---|---|
| [`front/`](front/) | Vite + React 18 + zustand | `:5173` | 캔버스 월드 엔진(A*·FSM)·회의 오케스트레이터·게임 샌드박스 하네스·오락실 시뮬 UI |
| [`back/`](back/) | Express (의존성 2개) | `:5175` | Gemini 프록시·Tavily 웹검색 키 로테이션·게임별 git 레포·JSON DB·RAG·공유 플레이어 |

## 빠른 시작

```bash
# 1. 백엔드 (:5175)
cd back && npm install && npm start

# 2. 프론트 (:5173) — 새 터미널
cd front && npm install && npm run dev
```

- `back/.env`에 `GEMINI_API_KEY`를 설정하세요. **키가 없으면 자동 mock 모드**로 전환되어 오프라인 데모가 가능합니다.
- 자세한 실행·환경변수·API 문서는 각 폴더의 README를 참고: [front/README.md](front/README.md) · [back/README.md](back/README.md)
