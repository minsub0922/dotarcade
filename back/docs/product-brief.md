# Product Brief — DOTCADE (도트케이드)

> BMAD Method · Phase 1 (Analyst) 산출물

## 한 줄 정의
**게임 스튜디오 운영 + 오락실 배포 시뮬레이션.** 플레이어는 도트 게임 스튜디오의 팀장이 되어, LLM 멀티에이전트 팀원들과 BMAD 방식의 회의로 *실제로 동작하는* 도트 미니게임을 만들고, 오락실에 배포해 20명의 가상 손님 에이전트로부터 피드백과 점수를 받는다.

## 문제 / 기회
- 게임 제작 시뮬레이션 장르는 많지만, **결과물이 진짜 게임인** 시뮬레이션은 없다.
- LLM 멀티에이전트(토론·역할분담·QA)를 게임 메카닉으로 승화 → "회의가 곧 제작 파이프라인".
- 20개 페르소나 에이전트의 병렬 피드백은 실제 플레이테스트 패널의 축소판.

## 타깃 사용자
- 1차: 본인(최민섭) — 개인 프로젝트/데모
- 2차: AI 에이전트 데모를 원하는 개발자·기획자

## 핵심 가치
1. 회의 = 제작: 멀티에이전트 토론이 실시간으로 보이고, 끝나면 게임팩이 나온다.
2. 배포 = 검증: 오락실 맵에서 20명이 실제로 게임을 실행·분석해 점수를 매긴다.
3. 반복 = 성장: 피드백 → 업그레이드 회의 → 버전 업 → 재배포 루프.

## 성공 기준 (MVP)
- 회의 시작 → 동작하는 게임팩 산출까지 무개입 완주율 ≥ 90% (자동 QA/수리 루프 포함)
- 오락실 시뮬레이션 20명 피드백 수집 10분 이내 (조기종료 지원)
- 기본 게임 3종 즉시 플레이 가능, 공유 링크로 외부 플레이 가능

## 제약
- 웹앱 (Node 백엔드 + 브라우저), LLM은 Gemini API 전용 (.env 키)
- 게임은 단일 파일 JS 캔버스 게임(게임팩 계약 준수), 샌드박스 iframe에서 실행
- LLM 불가 환경을 위한 모의(mock) 모드 필수
